公网 Index 节点（VPS）

开启后写入 node.conf（含 main-log-level、index-log-level 等，仅 file-log-level 不会写文件）；默认 logs/gnb-1001.log。修改后需重新「生成全部配置」并重启 gnb。

Index + Forward：address.conf 为 if|nodeid|...；仅 Index：为 i|nodeid|...，并自动关闭 set-fwdu0 / direct-forwarding

额外固定端口：逗号分隔，最多 4 个（含主端口共 5 个），便于防火墙固定放行 UDP

高级 node.conf 配置（Index + Forward 服务端）

es-argv 传给 gnb_es，公网 VPS 通常不需要 upnp；upnp 主要给内网节点用

性能 / 安全（gnb 高级选项）

crypto 默认 xor，无需配置。部分选项仅能通过 CLI 传递，会写入 scripts/start_linux.sh

detect-interval 格式：微秒,秒（默认 5000,367）；node-detect-worker 开启时调大可减轻路由器负担

pf-worker > 0 时 gnb 会关闭 unified-forwarding；packet-filter-worker-queue 增大会显著增加内存占用

内网节点

默认保留已有节点的 security / ed25519 密钥，仅更新 conf 与脚本；新增节点会自动生成密钥。勾选「重新生成密钥」后全部节点密钥将替换，已部署的内网节点需重新下载配置。
